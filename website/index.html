    Every Component Earns Its Place

    Five progressively richer models trained on the same UPFD split (5 seeds each). The jump to PropNet Fusion proves structural motif features and the attention gate deliver measurable gains — not decoration.

    • RF Motif — motif features alone, no text, no GNN
    • Text BERT — mean DistilBERT embeddings through Logistic Regression
    • Graph GAT — GNN over structural node features only (degree)
    • Hybrid GAT — GNN over full BERT node features
    • PropNet Fusion — Hybrid GAT + motif stream + learned attention gate

    Integrity & Legitimacy

    Three independent checks confirm the results are not inflated by data leakage.

    Label-Shuffle Sanity Check

    We randomly permuted all labels and re-ran the full ablation. Every model collapses to the 0.486 – 0.519 AUC range — confirming zero data leakage.

    • Train-only motif normalisation — scaler fitted on train split only
    • Split-overlap assertion — fails loudly if any claim appears in two splits
    • Label-shuffle check — all models collapse to AUC ≈ 0.50 under random labels
